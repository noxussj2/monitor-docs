---
title: SDK API 参考
description: 查看 track、captureError、flush、getContext、getOverview、stop 和 init 的调用方式与返回值。
---

SDK 加载后会暴露 `window.PulseWatch`。除 `getContext()` 和 `stop()` 外，涉及网络的方法通常返回 Promise。

## track()

记录自定义业务事件。

```ts
track(
    eventName: string,
    data?: Record<string, unknown>,
    options?: { path?: string }
): Promise<boolean>
```

```js
const accepted = await window.PulseWatch.track('plan_selected', {
    plan: 'professional',
    placement: 'pricing_page'
})
```

- 事件名不能为空，最长 100 个字符。
- 自定义数据会进行安全序列化，并自动附加 `_pulsewatch` 上下文。
- 返回 `true` 表示接口接受本次上报。

## captureError()

主动捕获已经被业务代码处理的异常。

```ts
captureError(
    error: Error | string | unknown,
    extra?: Record<string, unknown>
): Promise<boolean>
```

```js
await window.PulseWatch.captureError(error, {
    module: 'profile',
    operation: 'save_avatar'
})
```

## flush()

立即提交当前页面已经采集到的性能指标。

```ts
flush(): Promise<boolean>
```

```js
await window.PulseWatch.flush()
```

SDK 默认在页面隐藏、卸载、SPA 路由变化或启动约 10 秒后提交一次性能数据。通常不需要手动调用。

## getContext()

读取当前页面的监控上下文，不发起请求。

```ts
getContext(): {
    visitor_id: string
    session_id: string
    page_view_id: string
    url: string
    path: string
} | null
```

## getOverview()

查询网站公开访问概览，包括统计起始时间、今日和累计 PV/UV；查询失败时返回 `null`。

```ts
getOverview(): Promise<object | null>
```

```js
const overview = await window.PulseWatch.getOverview()
```

## stop()

停止采集、断开 PerformanceObserver，并恢复 SDK 包装过的 Fetch、XMLHttpRequest 和 History API。

```ts
stop(): void
```

```js
window.PulseWatch.stop()
```

## init()

停止现有客户端并按新配置重新初始化。

```ts
init(options: {
    projectKey: string
    apiBase?: string
    debug?: boolean
    autoTrack?: boolean
}): PulseWatchClient
```

## version

当前 SDK 构建版本字符串：

```js
console.log(window.PulseWatch.version)
```

::caution
不要依赖未在本页列出的内部 Client 属性和方法。它们不是稳定公开 API，后续版本可能变更。
::
