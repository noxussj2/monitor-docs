description: Integrate TraceVista with a Script, global configuration, or manual initialization, then verify reporting.

## Standard installation

Place this snippet in the page `<head>` and replace the API Key:

```html
<script
    defer
    src="https://apm.noxussj.top/monitor.min.js"
    data-project-key="mk_your_project_key">
</script>
```

`defer` avoids blocking HTML parsing. Do not install the SDK more than once on a page.

## API Key and bound domain

An API Key belongs to one monitored website. For every report, the server reads `Origin` first and falls back to `Referer`, extracts its hostname, and requires an **exact match** with the bound domain.

Matching is case-insensitive and ignores the protocol, port, and a trailing dot. It does not treat the apex domain, `www`, and other subdomains as equivalent.

| Bound domain | Page URL | Result |
| --- | --- | --- |
| `example.com` | `https://example.com/page` | Accepted |
| `www.example.com` | `https://www.example.com/page` | Accepted |
| `app.example.com` | `https://app.example.com:8443/page` | Accepted; protocol and port are ignored |
| `example.com` | `https://www.example.com/page` | 403 |
| `www.example.com` | `https://example.com/page` | 403 |
| `app.example.com` | `https://preview.example.com/page` | 403 |

::warning
On localhost or 127.0.0.1, the hostname does not match the domain bound to the API Key, so reports return 403. This is expected domain validation, not an SDK failure.
::

To monitor an apex domain, `www`, subdomains, preview, and production separately, create a monitored website and API Key for each hostname.

## Global configuration and manual initialization

Configuration can be declared before loading the Script:

```html
<script>
    window.TraceVistaConfig = {
        projectKey: 'mk_your_project_key',
        debug: false,
        autoTrack: true
    }
</script>
<script defer src="https://apm.noxussj.top/monitor.min.js"></script>
```

Use manual initialization only when the Key is unavailable at script-load time or monitoring must wait for consent:

```js
window.TraceVista.init({
    projectKey: 'mk_your_project_key',
    apiBase: 'https://apm.noxussj.top',
    debug: false,
    autoTrack: true
})
```

## Verify installation

Run `window.TraceVista.version` and `typeof window.TraceVista.track` in Console. You should see a version string and `"function"`. In Network, confirm a request to `/api/stats/track`.

## Troubleshoot a 403

If `/api/stats/track`, `/api/events/track`, `/api/vitals/track`, or `/api/errors/track` returns 403:

1. Open the request **Response** and read `message`; do not rely on the generic `Failed to load resource` line.
2. Check `Origin` in Request Headers, or `Referer` if Origin is absent.
3. Compare its hostname exactly with the bound domain, especially `www`, other subdomains, and preview domains.
4. Confirm the page uses the API Key generated for that website.

`{"message":"APIKEY does not match the current website domain"}` means the API is reachable but the source failed domain validation. Change the bound domain or use the matching website’s Key, then reload.
