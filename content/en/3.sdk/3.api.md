title: SDK API Reference
description: Learn when and how to use track, captureError, getOverview, and version.
---

After loading, the SDK exposes `window.PulseWatch`. This page lists only stable public APIs. Unlisted client properties and internal methods may change.

## track()

```ts
track(eventName: string, data?: Record<string, unknown>, options?: { path?: string }): Promise<boolean>
```

```js
const accepted = await window.PulseWatch.track('plan_selected', {
    plan: 'professional',
    placement: 'pricing_page'
})
```

Use it for conversion funnels and key product actions. The event name is required and limited to 100 characters. Custom data is safely serialized and receives a `_pulsewatch` object with visitor, session, page-view, URL, and path context. `true` means the API accepted the report.

## captureError()

```ts
captureError(error: Error | string | unknown, extra?: Record<string, unknown>): Promise<boolean>
```

```js
await window.PulseWatch.captureError(error, {
    module: 'profile',
    operation: 'save_avatar'
})
```

Use this for errors already handled by `try/catch`, or failures in critical payment, authentication, and upload flows. Reports include the stack, page context, recent breadcrumbs, and `extra` data.

## getOverview()

```ts
getOverview(): Promise<object | null>
```

Returns the website’s public traffic overview—statistics start time plus today and total PV/UV—or `null` on failure. It is suitable for lightweight public counters or Key verification. Use the Console for full analytics, errors, performance, and quota details.

```json
{"data":{"started_at":"2026-07-25 03:21:09.123","today":{"pv":36,"uv":12},"total":{"pv":1280,"uv":342}}}
```

## version

`window.PulseWatch.version` is the current SDK build string. Use it to diagnose CDN, cache, or deployment version differences, for example `1.0.0`.
