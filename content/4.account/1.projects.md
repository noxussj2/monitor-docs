---
title: 管理监控网站
description: 了解如何划分监控网站、配置域名和 API Key，以及重置或删除监控数据时的影响。
---

监控网站是 TraceVista 中的数据隔离、权限归属和接收量计算单位。一个监控网站通常对应一个正式站点或一个独立部署环境。

## 如何划分监控网站

推荐分别添加监控网站的情况：

- 生产、预发布和测试环境
- 彼此独立的产品或域名
- 需要单独计算接收量和趋势的业务线
- 生命周期、负责人或数据访问范围不同的站点

不建议为每个页面添加监控网站。页面路径已经包含在访问和性能记录中，可以在同一网站内分析。

::note
免费版账户可添加 **1 个监控网站**。PRO 账户可添加 **10 个监控网站**。
::

## 域名格式

添加监控网站时只填写常规域名，例如：

```text
app.example.com
```

不要包含 `https://`、端口、路径或查询参数。网站名称最长 100 个字符。

服务端校验 SDK 上报来源时，优先从请求 `Origin`、其次从 `Referer` 提取 hostname，与这里填写的域名进行完全相等比较。比较不区分大小写，忽略协议、端口和域名末尾的 `.`，但不会自动兼容 `www` 或其他子域名。例如：

- `example.com` 只匹配 `example.com`
- `www.example.com` 只匹配 `www.example.com`
- `app.example.com` 只匹配 `app.example.com`
- `example.com` 与 `www.example.com` 不会互相匹配
- `https://app.example.com:8443` 可以匹配 `app.example.com`，因为协议和端口不参与比较

来源缺失或无法解析时也不会通过校验。需要监控多个域名或多个环境时，应分别创建监控网站并使用各自的 API Key。

::warning
本地使用 localhost 或 127.0.0.1 时，hostname 与 API Key 绑定域名不一致，上报会返回 403。这是正常的域名校验，不是 SDK 故障。
::

## API Key

每个监控网站都有独立的 API Key。SDK 通过 `X-API-Key` 请求头提交 Key，服务端据此找到对应网站。

API Key 会出现在前端代码中，不应被当作后台登录密钥。管理网站、查询完整数据和执行删除操作仍需要用户登录凭据。

## 修改网站

可以修改网站名称与域名。修改不会自动改变已经部署在网站中的 Key，也不会迁移或清空历史监控数据。

## 清空监控数据

“清空数据”会删除该监控网站的：

- 页面访问
- 业务事件
- 性能指标
- 错误记录

网站、域名和 API Key 会保留。清空数据不会返还当月已经使用的接收量，该操作不可通过控制台自动恢复，执行前应确认网站和数据范围。

## 数据接收开关

可以在网站设置中关闭访问统计、业务事件、性能指标或错误记录。关闭后，服务端会忽略对应类型的数据，不计入账号本月上下文 data 接收量和事件触发次数。

## 删除网站

删除监控网站会同时删除网站配置和关联 API Key。网站中仍然存在的旧 SDK 代码将无法继续正常上报。正式删除前，建议先从网站移除 SDK 或替换成其他网站的 API Key。
