---
title: 私隱、安全與收集邊界
description: 了解 SDK 預設收集及明確不收集的內容，以及接入方對自訂資料的責任。
---

TraceVista 遵循資料最小化原則：預設只收集分析頁面體驗所需的技術資料，不讀取輸入值、Cookie 或頁面正文。接入方仍須按服務地區、用戶群體和適用法律完成私隱評估與告知。

## 預設收集

- URL、路徑、標題和來源
- 隨機訪客、工作階段和頁面瀏覽識別碼
- 視窗、螢幕、語言、時區和部分網絡能力
- Performance API 提供的效能時長
- JavaScript、Promise、資源和介面錯誤
- 點擊元素的標籤、ID 及最多兩個 class
- SDK 版本和導覽類型

## 預設不收集

- 輸入框及表單輸入值、密碼
- Cookie、登入 Token 及授權標頭
- 頁面正文、完整 DOM 或點擊元素文字

監控請求使用 `credentials: 'omit'`，不會主動攜帶目標網站 Cookie。

## 自訂資料責任

`track()` 的資料和 `captureError()` 的附加資訊由接入方決定。建立欄位白名單，不要直接傳送完整用戶物件、表單、請求標頭或後端回應。

```js
window.TraceVista.track('checkout_failed', {
    payment_method: 'card',
    reason_code: 'issuer_declined'
})
```

如須先取得用戶同意，請在同意後才載入或初始化 SDK。撤回同意後應阻止後續初始化；撤回不會自動刪除已提交資料或本機訪客識別碼。
