title: SDK API 參考
description: 查看 track、captureError、getOverview 及 version 的用途、返回值與示例。
---

SDK 載入後會公開 `window.PulseWatch`。本頁只列出穩定公開 API；未列出的內部屬性可能在後續版本變更。

## track()

```ts
track(eventName: string, data?: Record<string, unknown>, options?: { path?: string }): Promise<boolean>
```

```js
const accepted = await window.PulseWatch.track('plan_selected', {
    plan: 'professional',
    placement: 'pricing_page'
})
```

用於轉化漏斗及關鍵業務動作。事件名稱不可為空且最多 100 個字元；自訂資料會安全序列化並附加 `_pulsewatch` 的訪客、工作階段、頁面、URL 及路徑內容。返回 `true` 代表介面接受本次上報。

## captureError()

```ts
captureError(error: Error | string | unknown, extra?: Record<string, unknown>): Promise<boolean>
```

```js
await window.PulseWatch.captureError(error, {
    module: 'profile',
    operation: 'save_avatar'
})
```

用於已被 `try/catch` 處理而不再冒泡的錯誤，或支付、登入、上載等關鍵鏈路失敗。記錄包含錯誤堆疊、頁面內容、最近麵包屑及 `extra`。

## getOverview()

```ts
getOverview(): Promise<object | null>
```

查詢網站的公開瀏覽概覽，包括統計開始時間、今日及累計 PV/UV；失敗時返回 `null`。適合在前台顯示輕量統計或驗證 Key。完整分析、錯誤、效能及額度資料仍應使用管理後台。

```json
{"data":{"started_at":"2026-07-25 03:21:09.123","today":{"pv":36,"uv":12},"total":{"pv":1280,"uv":342}}}
```

## version

`window.PulseWatch.version` 是目前 SDK 的版本字串，可用於排查 CDN、快取及部署版本，例如 `1.0.0`。
