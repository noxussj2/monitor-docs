---
title: SDK 設定
description: 設定 projectKey、apiBase、debug 及 autoTrack，並處理多環境與 CSP。
---

SDK 優先使用 Script 的 `data-*` 屬性；如需在載入前動態注入設定，可使用全域 `TraceVistaConfig`。少數進階場景可傳入 `TraceVista.init()`。

## 設定項目

| 設定 | Script 屬性 | 類型 | 預設值 | 說明 |
| --- | --- | --- | --- | --- |
| `projectKey` | `data-project-key` | `string` | 空 | 必填，識別接收資料的監控網站 |
| `apiBase` | `data-api-base` | `string` | SDK Script 域名 | 自訂監控介面基礎地址 |
| `debug` | `data-debug` | `boolean` | `false` | 在 Console 顯示除錯資訊 |
| `autoTrack` | `data-auto-track` | `boolean` | `true` | 自動記錄頁面瀏覽 |

## 除錯模式

在 Script 加入 `data-debug="true"`。日誌以 `[TraceVista]` 開頭，會顯示啟動內容及上報失敗狀態；定位後建議在正式環境關閉。

## 關閉自動瀏覽追蹤

設定 `data-auto-track="false"`。效能及錯誤監聽仍會安裝，`track()`、`captureError()` 等公開方法仍可使用。現版本沒有獨立的手動頁面瀏覽 API，除非只需要錯誤或事件，否則建議保持自動追蹤。

## 自訂介面地址

```js
window.TraceVista.init({
    projectKey: 'mk_your_project_key',
    apiBase: 'https://monitor-api.example.com'
})
```

介面必須允許網站來源的 CORS，並接受 `Content-Type` 和 `X-API-Key` 標頭。

## 多環境及 CSP

為正式、預發佈和測試環境分別建立監控網站和 API Key。若網站使用 CSP，至少允許：

```text
script-src https://apm.noxussj.top
connect-src https://apm.noxussj.top
```

把規則合併至現有政策，不要覆蓋完整 CSP。
