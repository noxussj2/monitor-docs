## 標準安裝

把以下程式碼放入頁面 `<head>`，並替換 API Key：

```html
<script
    defer
    src="https://apm.noxussj.top/monitor.min.js"
    data-project-key="mk_your_project_key">
</script>
```

`defer` 避免阻塞 HTML 解析。請勿在同一頁重複安裝 SDK。

## API Key 與綁定域名

API Key 屬於一個監控網站。每次上報時，伺服器優先讀取 `Origin`，缺失時讀取 `Referer`，提取 hostname 後與網站綁定域名作**完全相等**比較。

比較不區分大小寫，並忽略協定、連接埠及域名末尾的 `.`；但不會自動把根域名、`www` 和其他子域名視為相同。

| 綁定域名 | 頁面地址 | 結果 |
| --- | --- | --- |
| `example.com` | `https://example.com/page` | 通過 |
| `www.example.com` | `https://www.example.com/page` | 通過 |
| `app.example.com` | `https://app.example.com:8443/page` | 通過，忽略協定和連接埠 |
| `example.com` | `https://www.example.com/page` | 403 |
| `www.example.com` | `https://example.com/page` | 403 |
| `app.example.com` | `https://preview.example.com/page` | 403 |

::warning
本機使用 localhost 或 127.0.0.1 時，hostname 與 API Key 綁定域名不一致，上報會返回 403。這是正常的域名校驗，並非 SDK 故障。
::

如要監控根域名、`www`、子域名、預覽及正式環境，請分別建立監控網站並使用各自 API Key。

## 全域設定與手動初始化

Script 載入前可設定：

```html
<script>
    window.TraceVistaConfig = {
        projectKey: 'mk_your_project_key',
        debug: false,
        autoTrack: true
    }
</script>
<script defer src="https://apm.noxussj.top/monitor.min.js"></script>
```

只有在 Script 載入時尚未取得 Key，或必須等待用戶同意時，才需要手動初始化：

```js
window.TraceVista.init({
    projectKey: 'mk_your_project_key',
    apiBase: 'https://apm.noxussj.top',
    debug: false,
    autoTrack: true
})
```

## 驗證安裝

在 Console 執行 `window.TraceVista.version` 和 `typeof window.TraceVista.track`，應看到版本字串及 `"function"`。再於 Network 確認 `/api/stats/track` 請求。

## 403 排查

若 `/api/stats/track`、`/api/events/track`、`/api/vitals/track` 或 `/api/errors/track` 返回 403：

1. 開啟請求 **Response**，查看 `message`，不要只看 `Failed to load resource`。
2. 檢查 Request Headers 的 `Origin`，若沒有則查看 `Referer`。
3. 與綁定域名逐字比較 hostname，尤其留意 `www`、其他子域名及預覽域名。
4. 確認使用的是該監控網站的 API Key。

`{"message":"APIKEY 與當前網站域名不匹配"}` 表示介面可連接，但來源未通過域名校驗。修改綁定域名或換用相應網站的 Key 後重新整理頁面。
