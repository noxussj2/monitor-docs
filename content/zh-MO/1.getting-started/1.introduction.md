TraceVista 是面向 Web 應用程式的**真實用戶監控平台**（Real User Monitoring，簡稱 RUM）。它透過運行於用戶瀏覽器的輕量 SDK，自動收集瀏覽、效能和錯誤資料，並記錄你透過 `track()` 手動上報的關鍵業務事件，再把這些訊號整理成可查詢、可比較的產品資料。

它不只回答「伺服器是否在線」，更關注真實體驗：

- 用戶能否順利開啟頁面，主要內容多久才顯示？
- 點擊、輸入及路由切換是否及時回應？
- 頁面有否意外跳動、資源載入失敗或介面報錯？
- 問題影響哪些頁面、瀏覽器、裝置及用戶？
- 修正上線後，真實用戶體驗是否確實改善？

## 為何需要真實用戶監控

本機開發、自動化測試和 Lighthouse 都很重要，但通常處於可控環境。真實用戶可能使用較舊的手機、較弱的網絡或不同瀏覽器，亦可能由不同地區瀏覽。只有在真實瀏覽現場收集的資料，才能反映這些差異。

| 訊號 | 解決的問題 | 常見用途 |
| --- | --- | --- |
| 頁面瀏覽 | 誰在何時瀏覽了哪個頁面 | PV/UV、趨勢、來源、熱門頁面 |
| 效能指標 | 用戶看到內容及完成互動所需時間 | 找出緩慢頁面、定位載入或主執行緒瓶頸 |
| 前端錯誤 | 瀏覽器內發生了哪些失敗 | 修正 JS、Promise、資源及介面錯誤 |
| 業務事件 | 用戶有否完成關鍵動作 | 追蹤註冊、購買、搜尋及提交等行為 |

## 平台如何運作

::steps
### 新增監控網站

在管理後台新增需要監控的網站，填寫名稱和正式域名。平台會為網站產生獨立 API Key。

### 安裝 SDK

把帶有 `data-project-key` 的 Script 放進頁面。SDK 會自動開始收集。

### 觀察真實資料

瀏覽網站後，管理後台會逐步顯示瀏覽、效能、錯誤及事件資料。

### 優化並驗證

優先修正影響大、頻率高的問題；上線後繼續觀察同一指標，確認優化結果。
::
