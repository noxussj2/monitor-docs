---
title: 管理監控網站
description: 了解如何劃分監控網站、設定域名和 API Key，以及重設或刪除資料的影響。
---

監控網站是 PulseWatch 的資料隔離、權限歸屬及接收量計算單位，通常對應一個正式網站或獨立部署環境。

## 如何劃分監控網站

建議為正式、預發佈和測試環境、獨立產品或域名、需要分開統計的業務線建立不同網站。毋須為每個頁面建立網站，頁面路徑已包含於瀏覽和效能記錄。

::note
免費版帳戶可新增 **1 個監控網站**；PRO 帳戶可新增 **10 個監控網站**。
::

## 域名格式

只填寫一般域名，例如 `app.example.com`，不要包含 `https://`、連接埠、路徑或查詢參數。

伺服器優先由 `Origin`、其次由 `Referer` 提取 hostname，與綁定域名作完全相等比較。比較不區分大小寫，忽略協定、連接埠及末尾的 `.`，但不會自動兼容 `www` 或其他子域名：

- `example.com` 只匹配 `example.com`
- `www.example.com` 只匹配 `www.example.com`
- `app.example.com` 只匹配 `app.example.com`
- `example.com` 與 `www.example.com` 不會互相匹配
- `https://app.example.com:8443` 可匹配 `app.example.com`

來源缺失或無法解析也不會通過。多個域名或環境應分別建立網站並使用各自 API Key。

::warning
本機使用 localhost 或 127.0.0.1 時，hostname 與 API Key 綁定域名不一致，上報會返回 403。這是正常的域名校驗，並非 SDK 故障。
::

## API Key 與網站變更

每個網站都有獨立 API Key，SDK 以 `X-API-Key` 標頭提交。Key 可出現在前端程式碼，但不是管理後台登入密鑰。修改網站名稱或域名不會更改 Key，也不會遷移或清除歷史資料。

## 清除資料、接收開關及刪除網站

「清除資料」會刪除頁面瀏覽、業務事件、效能和錯誤記錄，但保留網站、域名和 API Key，亦不會返還當月已用額度。

在網站設定關閉某類資料後，伺服器會忽略該類資料且不計入用量。刪除網站則會同時刪除設定及 API Key；頁面內的舊 SDK 程式碼將不能繼續上報。
