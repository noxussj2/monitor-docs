前端錯誤發生在用戶瀏覽器，伺服器日誌未必可見。PulseWatch SDK 由全域異常、資源載入及請求鏈路擷取常見失敗，並附加頁面內容。

## 自動擷取範圍

| 類型 | 來源 | 示例 |
| --- | --- | --- |
| `js_error` | `window.error` | 未定義函數、運行時異常 |
| `promise_error` | `unhandledrejection` | 未處理的 Promise 拒絕 |
| `resource_error` | 資源錯誤 | Script、CSS、圖片載入失敗 |
| `api_error` | Fetch / XMLHttpRequest | 網絡失敗、HTTP 4xx/5xx |

SDK 自己的上報請求會排除，以免監控失敗形成遞迴錯誤。

## 錯誤內容與保護

記錄可能包括名稱、訊息、堆疊、URL、路徑、訪客/工作階段/頁面識別碼、環境資料，以及最近的點擊和路由麵包屑。點擊只記錄標籤、ID 及最多兩個 class，不記錄文字或輸入值。

相同錯誤短時間內會被抑制，單一客戶端亦有每分鐘上報限制。這些保護可減少錯誤風暴，但不代替修正根本原因。

## 主動報告已處理的錯誤

```js
try {
    await saveProfile()
} catch (error) {
    await window.PulseWatch.captureError(error, {
        module: 'profile',
        operation: 'save'
    })
}
```

附加資料不要包含密碼、Token、完整表單或未篩選的伺服器回應。詳見 [私隱與收集邊界](/zh-MO/sdk/privacy)。
